# Code of Conduct

This project exists to make the web easier on the eyes. To keep it healthy, everyone taking part — in issues, pull requests, discussions, or any other project space — agrees to the standards below.

## Standards

**Expected:**

- Be respectful and professional.
- Keep feedback constructive and about the work, not the person.
- Assume good intent, and ask for clarification before reacting.
- Stay on topic and help move the project forward.

**Not tolerated:**

- Personal attacks, insults, or name-calling.
- Harassment, threats, or sustained disruption.
- Trolling, derailing, or hostile behavior.
- Sharing others' private information without consent.

## Enforcement

Maintainers may edit, reject, or remove contributions that violate these standards, and may block repeat offenders.

To report a problem, contact the maintainer privately via the [KJ Shuvo GitHub profile](https://github.com/kjshuvo).

This Code of Conduct applies in all project spaces and is enforced at the maintainers' discretion.
